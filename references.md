## Citation guidance

If citing findings from this repository, distinguish:

- Claims first published by Omolewa, which should cite the original article.
- Independent matches and extensions supported by this repository's artifacts and hashes.
- Speculation about rollout, the developer's intentions or legal liability, which is **not** established by code presence.

No claim is made that these earlier authors participated in, reviewed or endorsed this repository.
